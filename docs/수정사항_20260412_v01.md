## 목표 아키텍처 (최종 확정)

```
[30분 cron] — scanJob
  └─ 뒷차기2(seq=30) 조건검색
       ├─ DART 위험공시 필터 (위험 종목 자동 제외)
       └─ candidate_stocks DB 저장 (이전 결과 초기화 후)

[1분 cron] — tradingJob
  └─ candidate_stocks 로드
       └─ 각 후보 종목에 대해:
            ├─ [A] 레인보우 라인 체크 (차트 조회) → 진입 시점 판단
            │       ├─ 미보유 + CL선 ≤ 50 + unitCount > 0 → 신규 매수 후보
            │       └─ 보유중 + 매수 CL선보다 1단계 하락 → 추가매수 후보
            ├─ [B] GPT 종합분석 → 신뢰도(confidence) 산출
            │       ├─ analyzeStock()  → themeScore  (레인보우+모멘텀, GPT)
            │       ├─ integratedAnalysis() → newsScore + financialScore (뉴스+DART+재무, GPT)
            │       ├─ liquidityScore  (거래량, 규칙)
            │       └─ institutionalScore (거래량, 규칙)
            ├─ [C] 가중치 적용 → 최종 confidence
            │       confidence = (themeScore×테마% + newsScore×뉴스% +
            │                     financialScore×재무% + liquidityScore×유동성% +
            │                     institutionalScore×기관%) / 100
            ├─ [D] 필터 통과 여부 판단
            │       ├─ confidence < minAiConfidence → 스킵
            │       ├─ requireGoodFinancials ON → financialScore < 60 → 스킵
            │       ├─ requireHighLiquidity ON  → liquidityScore < 40 → 스킵
            │       └─ DART 위험공시 감지 → 무조건 스킵
            └─ [E] 통과 시 → 매수/추가매수 실행 (유닛 기반)

[매일 16:00] — learningJob
  └─ 거래기록 + 종목정보 → winrate 분석 → 모델 파라미터 자동 조정
```

### 핵심 설계 원칙

- **레인보우** = 진입 시점(언제 살지)을 결정
- **GPT 분석** = 종목 품질(살 가치가 있는지)을 결정  
- **가중치(비중 슬라이더)** = GPT가 준 5개 점수를 얼마나 반영할지 규칙
- 두 가지가 **반드시 함께** 작동해야 함. 둘 중 하나만으로는 불완전

## 레인보우 라인 번호 체계

```
n=0  MAX    percentage=100  overbought
n=1  10%    percentage=90   sell
n=2  20%    percentage=80   sell
n=3  30%    percentage=70   sell
n=4  40%    percentage=60   primary-buy
n=5  CL     percentage=50   primary-buy  ← 초록 (Center Line)
n=6  60%    percentage=40   primary-buy  ← 파랑 (blue)
n=7  70%    percentage=30   scale-in     ← 남색 (navy)
n=8  80%    percentage=20   scale-in     ← 보라 (purple)
n=9  90%    percentage=10   deep-value
n=10 MIN    percentage=0    deep-value
```

`currentLine` = `Math.round(currentPercent / 10) * 10` (10단위 반올림)

매수 대상 라인 (초록 이하):
| 라인명 | currentLine 값 |
|--------|---------------|
| 초록 (CL) | 50 |
| 파랑 | 40 |
| 남색 | 30 |
| 보라 | 20 |
| 최하위 | 10 |

## 긴급 복원 작업 (현재 진행)

### R-1. `trade-executor.service.ts` — GPT 분석 복원

**현재 상태:** `comprehensiveMarketAnalysis()` 함수가 GPT 없이 단순 키워드/임계값 계산  
**목표:** 원본 `comprehensiveAiAnalysis()` 복원 — GPT 2개 병렬 호출

```typescript
// 복원할 구조
async comprehensiveAiAnalysis(
  stock: { code: string; name: string; price: number },
  settings: AutoTradingSettings,
  kiwoomService: KiwoomService,
  aiService: AIService                          // ← 생성자 주입 복원 필요
): Promise<AiAnalysisResult> {

  // 1단계: 5개 데이터 병렬 수집
  const [priceResult, chartResult, ratiosResult, newsResult, dartResult] = await Promise.allSettled([
    kiwoomService.getStockPrice(stock.code),
    kiwoomService.getStockChart(stock.code, 'D'),
    kiwoomService.getFinancialRatios(stock.code),
    getNewsService().getStockNews(stock.code, stock.name, 10),
    getDartService().getFilingsByStockCode(stock.code, 30),
  ]);

  // 2단계: 레인보우 차트 계산
  // ...ohlcv 정규화 + RainbowChartAnalyzer.analyze()

  // 3단계: PER/PBR/ROE/EPS/BPS 추출
  // ...ratiosRaw → financialRatios 객체

  // 4단계: 뉴스 + DART 추출

  // 5단계: GPT 2개 병렬 호출
  const [stockAnalysis, integrated] = await Promise.all([
    aiService.analyzeStock({
      stockCode, stockName, currentPrice, rainbowChart,
    }),                                           // → themeScore
    aiService.integratedAnalysis({
      stockCode, stockName, currentPrice,
      financialRatios, priceHistory, news, dartFilings,
    }),                                           // → newsScore + financialScore
  ]);

  // 6단계: 거래량 기반 점수 (규칙, GPT 불필요)
  const liquidityScore     = volume >= 500_000 ? 80 : volume >= 100_000 ? 65 : volume >= 50_000 ? 45 : 25;
  const institutionalScore = volume >= 1_000_000 ? 75 : volume >= 500_000 ? 65 : volume >= 100_000 ? 55 : volume >= 50_000 ? 45 : 35;

  // 7단계: 가중치 곱하기 → 최종 confidence
  const weights = {
    theme:         parseFloat(settings.themeWeight.toString()),
    news:          parseFloat(settings.newsWeight.toString()),
    financials:    parseFloat(settings.financialsWeight.toString()),
    liquidity:     parseFloat(settings.liquidityWeight.toString()),
    institutional: parseFloat(settings.institutionalWeight.toString()),
  };
  const denominator = (weights.theme + weights.news + weights.financials + weights.liquidity + weights.institutional) || 100;
  const confidence = Math.min(100, Math.max(0, (
    stockAnalysis.themeScore   * weights.theme +
    integrated.newsScore       * weights.news +
    integrated.financialScore  * weights.financials +
    liquidityScore             * weights.liquidity +
    institutionalScore         * weights.institutional
  ) / denominator));

  return { confidence, hasGoodFinancials: integrated.financialScore >= 60,
           hasHighLiquidity: liquidityScore >= 40, dartDangerKeyword,
           themeScore: stockAnalysis.themeScore, newsScore: integrated.newsScore,
           financialsScore: integrated.financialScore, liquidityScore, institutionalScore };
}
```
