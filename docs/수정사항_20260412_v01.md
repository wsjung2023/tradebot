## 개요

4개 이미지(이전 세션 대화 스크린샷) + 코드베이스 정밀 분석 결과를 토대로 작성.  
**목표 구조:**
- **30분 cron** → 뒷차기2(seq=30) 조건검색 실행 → 결과 종목을 `candidate_stocks` DB에 저장
- **1분 cron** → `candidate_stocks` 종목들 레인보우 라인 체크 → 보유 여부 확인 → 매수/추가매수/매도

## 우선순위 2 — 자동매매 아키텍처 재구성

### 현재 구조 (문제)
```
매 1분마다 (cron: * * * * *)
  └─ DB 조건검색식 N개 전부 실행 (에이전트로 HTS 조건검색)
       └─ 각 종목 AI분석 (GPT-4 호출) + 레인보우 체크
            └─ 신호 있으면 바로 매수 (보유 여부 확인 없음)
```

### 목표 구조
```
매 30분마다 (cron: */30 * * * *)  ← scanJob
  └─ 뒷차기2(seq=30) 조건검색 실행 (에이전트)
       └─ 결과 종목 → candidate_stocks DB 저장 (userId, modelId 기준)

매 1분마다 (cron: * * * * *)  ← evaluateJob  
  └─ candidate_stocks에서 해당 userId 종목 로드
       └─ 각 종목 레인보우 라인 체크 (차트 조회)
            ├─ 미보유 + CL선 파랑(≤20%) → 신규 매수
            ├─ 보유중 + 파/남/보 라인 이하 → 추가 매수
            └─ 보유중 + CL 위(초록↑) → 매도 신호 → 익절/손절 체크
```

### 2-D. 트레이드 실행 로직 개선
**파일:** `server/services/trade-executor.service.ts`  

**신규 메서드: `evaluateCandidateStock()`** (기존 `evaluateStock()` 대체)

```typescript
async evaluateCandidateStock(model, settings, candidate, kiwoomService, aiService) {
  const stock = { code: candidate.stockCode, name: candidate.stockName, price: 0, volume: 0 };
  
  // 1. 현재가 조회 (에이전트 경유)
  const priceData = await kiwoomService.getStockPrice(stock.code);
  stock.price = parseFloat(priceData.output?.stck_prpr ?? '0');
  if (!stock.price) return;

  // 2. 보유 여부 확인
  const config = (model.config as any) || {};
  const accounts = await storage.getKiwoomAccounts(model.userId);
  const activeAccount = accounts.find((a: any) => a.id === config.accountId);
  if (!activeAccount) return;
  
  const holdings = await storage.getHoldings(activeAccount.id);
  const existingHolding = holdings.find(h => h.stockCode === stock.code);

  // 3. 레인보우 라인 계산 (차트 조회)
  const rainbowEval = await this.evaluate10LineRainbow(stock, settings, kiwoomService);

  if (!existingHolding) {
    // ── 미보유: CL선 파랑(≤20%)이면 신규 매수 ──
    if (rainbowEval.action === 'buy' && rainbowEval.currentLine <= 20) {
      await this.executeBuy(model, settings, stock, rainbowEval, /* aiAnalysis */ null, kiwoomService);
    }
  } else {
    // ── 보유중: 파/남/보(≤20%) 이하면 추가 매수 ──
    if (rainbowEval.currentLine <= 20) {
      await this.executeAdditionalBuy(model, settings, stock, existingHolding, rainbowEval, kiwoomService);
    }
    // ── 보유중: CL 초록 이상(>20%)이면 매도 검토 ──
    else if (rainbowEval.action === 'sell') {
      await this.executeSell(model, settings, stock, rainbowEval, kiwoomService);
    }
  }
}
```
