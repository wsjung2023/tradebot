## 현재 구현 상태 (AS-IS) — 코드 실측 기준

> 2026-06-11 소스코드 직접 분석 결과

### 보안 현황 (예상보다 잘 되어 있음)
| 영역 | 상태 | 구현 방식 |
|------|------|-----------|
| Kiwoom API 키 암호화 | ✅ 완료 | AES-256-GCM (salt:iv:tag:encrypted 형식) |
| 암호화 마스터 키 | ✅ 완료 | `ENCRYPTION_KEY` 환경변수, 하드코딩 없음 |
| 비밀번호 해싱 | ✅ 완료 | bcrypt (10 rounds) |
| 세션 쿠키 보안 | ✅ 완료 | httpOnly, secure, sameSite=lax |
| 보안 헤더 | ✅ 완료 | Helmet + CSP (프로덕션만) |
| Rate Limiting | ✅ 완료 | API 200/15분, 인증 10/15분 |
| API 키 브라우저 노출 방지 | ✅ 완료 | masking + 조회 API 없음 |
| 이메일 평문 저장 | ⚠️ 부분 | 로그인 식별자이므로 평문 불가피, 유출 시 노출 |
| 계좌번호 평문 저장 | ⚠️ 부분 | 공개 정보 성격이나 SaaS에서는 암호화 검토 필요 |
| **ALLOWED_EMAILS 하드코딩** | ❌ 문제 | `server/auth.ts`에 특정 이메일 배열 하드코딩 |
| **Role 기반 접근제어** | ❌ 없음 | 모든 사용자 동일 권한, admin 라우트 무방비 |
| CORS 명시 설정 | ❌ 없음 | 기본값에 의존 |

### S-4. Railway 보안 체계

**Railway가 제공하는 것:**
- TLS/HTTPS 자동 적용 (Let's Encrypt) ✅
- 환경변수 암호화 저장 ✅
- Private Networking (서비스 간 통신 격리) ✅
- DDoS 기본 방어 ✅
- PostgreSQL 자동 백업 (매일) ✅

**Railway가 제공하지 않는 것 (직접 대응):**
- WAF (Web Application Firewall) — Rate limiter로 대체
- DB 백업 암호화 별도 보장 없음 — 민감 데이터는 이미 컬럼 레벨 암호화로 대응됨
- 취약점 스캔 — Sentry + 코드 리뷰로 대응

**추가 조치:**
- [ ] CORS 명시 설정 (`server/index.ts`에 `cors` 미들웨어 추가, Railway 도메인만 허용)
- [ ] DB SSL 연결 강제 (`DATABASE_URL`에 `?sslmode=require` 확인)
- [ ] 프로덕션 로그에 민감 데이터(API 키, 계좌번호) 출력 금지 확인

### S-6. Audit 로그 (감사 로그)

**필요 이유:** 거래 SaaS에서 "내가 이 API 키를 등록한 적 없다", "구독이 무단 변경됐다" 류의 분쟁은 반드시 발생함. 로그 없으면 방어 불가.

**로깅 대상 (최소한):**

| 이벤트 | 기록 항목 |
|--------|----------|
| API 키 등록/삭제 | userId, 시각, IP, 행동 |
| 계좌 등록/삭제 | userId, 시각, IP |
| 구독 상태 변경 | userId, 이전/이후 tier, 변경 주체(paddle webhook/admin) |
| 어드민 액션 | adminId, 대상 userId, 행동, 시각 |
| 로그인 실패 | 이메일, IP, 시각 (이미 rate limiter 있으나 로그는 별도) |
| 자동매매 ON/OFF | userId, modelId, 시각 |

**구현 방식 (간단하게):**
```typescript
// server/utils/audit-logger.ts
export async function auditLog(event: {
  userId: string;
  action: string;
  detail?: Record<string, unknown>;
  ip?: string;
}) {
  await db.insert(auditLogs).values({
    userId: event.userId,
    action: event.action,
    detail: event.detail ?? {},
    ip: event.ip ?? null,
    createdAt: new Date(),
  });
}
```

- [ ] API 키/계좌/구독/어드민 라우트에 auditLog 호출 삽입
