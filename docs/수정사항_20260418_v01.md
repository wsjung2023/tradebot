  catalystScore: number;    // 0~20 촉매 존재 여부 (3~9개월 내)
  moonshotSignals: string[]; // 떡상 조건 3개

  targetPrice: number | null;
  reasoning: string;

**프롬프트 교체 위치 (line 93~136):**

현재 영어로 된 프롬프트를 아래 구조로 교체. 입력 데이터는 동일(레인보우차트 + 가격이력).

```text
[시스템 프롬프트]
너는 한국 주식 리서치 엔진이다.
"좋은 회사/좋은 주식/좋은 타이밍"을 분리해서 평가하고 JSON만 반환한다.

[유저 프롬프트 구조]
종목코드/종목명/현재가/240일 레인보우차트(고가,저가,CL,currentLine)/최근 20일 가격+거래량

요구사항:
1. stockType 분류
   - growth: 매출/이익 실제 개선 중
   - turnaround: 현재 숫자는 나쁘나 회복 시그널
   - theme_option: 내러티브 강하나 숫자 약함
   - lottery: 유증/CB/상폐 리스크 높음
   - stale: 장기 적체, 재평가 근거 약함

2. narrativeScore (0~20)
   - 현재 시장이 선호하는 테마/키워드 해당 여부
   - 설명하기 쉬운 강한 스토리 여부
   
3. realityScore (0~20)  
   - 실제 팔리는 제품/매출/고객사 존재 여부
   - 발표자료 속 이야기 vs 현실 사업 구분
   
4. catalystScore (0~20)
   - 3~9개월 내 허가/수주/상용화/실적발표 이벤트 존재 여부
   - 뉴스만 많고 실제 촉매 없으면 낮게
   
5. moonshotSignals: 재평가에 필요한 핵심 이벤트 3개 (한국어)
6. invalidationConditions: 강세 시나리오가 깨지는 조건 3개 (한국어)

반환 JSON:
{
  "action": "buy|sell|hold",
  "confidence": 0~100,
  "stockType": "growth|turnaround|theme_option|lottery|stale",
  "narrativeScore": 0~20,
  "realityScore": 0~20,
  "catalystScore": 0~20,
  "moonshotSignals": ["이벤트1","이벤트2","이벤트3"],
  "invalidationConditions": ["조건1","조건2","조건3"],
  "targetPrice": 숫자 or null,
  "reasoning": "한국어 2~3문장"
}
```

**파싱 수정 (line 152~162):** 기존 themeScore/newsScore 대신 위 필드 clamp/검증 처리.

**프롬프트 교체 위치 (line 424~459):**

입력 데이터는 동일(PER/PBR/ROE/EPS, 뉴스, DART, 가격이력).

```text
[유저 프롬프트 구조]
종목명/현재가 + 재무지표(PER,PBR,ROE,EPS) + 뉴스 + DART공시 + 최근가격

요구사항:
1. financeHealthScore (0~15): 재무 체력
   - 현금 보유 수준 / 영업현금흐름 방향 (PER,ROE로 추정)
   - 자본잠식 신호 여부
   - 높을수록 체력 좋음

2. earningsScore (0~15): 실적 방향성
   - 가격 흐름 + 뉴스에서 YoY 성장/적자축소/흑자전환 여부 추정
   - 단순 흑자전환인지 본업 개선인지 구분

3. penaltyScore (0 이하): 감점
   감점 항목 (발견 시 해당 점수 차감):
   - DART에 유상증자/전환사채/BW 공시 → -15
   - DART에 관리종목/상폐/계속기업 경고 → -20
   - 거래정지/투자경고/불성실공시 → -10
   - 최근 20일 15% 이상 급등 후 현재가 고점 근처 → -10
   - 대주주/경영진 횡령/배임 공시 → -10
   여러 항목 중복 적용 가능, 최소 -30

4. penaltyDetail: 감점 항목 사유 목록 (한국어)

5. newsScore (0~100): 뉴스 감성 점수 (보조 참고용)

반환 JSON:
{
  "financeHealthScore": 0~15,
  "earningsScore": 0~15,
  "penaltyScore": -30~0,
  "penaltyDetail": ["사유1","사유2"],
  "newsScore": 0~100,
  "newsAnalysis": "뉴스 분석 (2문장, 한국어)",
  "financialAnalysis": "재무 분석 (2문장, 한국어)",
  "summary": "종합 의견 (3문장, 한국어)",
  "risks": ["리스크1","리스크2","리스크3"],
  "catalysts": ["촉매1","촉매2","촉매3"]
}
```

const timingScore = currentLine <= 20 ? 10
  : currentLine <= 30 ? 9
  : currentLine <= 40 ? 8
  : currentLine <= 50 ? 6   // CL선(그린) 인근 = 적정
  : currentLine <= 60 ? 4
  : currentLine <= 70 ? 2

              + realityScore        // 0~20 (analyzeStock에서)
              + financeHealthScore  // 0~15 (integratedAnalysis에서)
              + earningsScore       // 0~15 (integratedAnalysis에서)
              + catalystScore       // 0~20 (analyzeStock에서)
              + timingScore;        // 0~10 (currentLine 변환)

// penaltyScore는 음수 (-30~0)

            : confidence >= 60 ? 'B'
            : confidence >= 45 ? 'C'

const hasGoodFinancials = financeHealthScore >= 8; // 0~15 기준 재조정

if (maxDailyLoss > 0) {
  const todayOrders = await storage.getOrders(accountId, 200);

  const todayLoss = todayOrders

      return sum + (pnl < 0 ? pnl : 0);
    }, 0);
  
  if (Math.abs(todayLoss) >= maxDailyLoss) {
    // engine_notification: [긴급차단] 일일 손실 상한 도달 ({todayLoss}원 / 상한 {maxDailyLoss}원) — 당일 자동매매 중단
