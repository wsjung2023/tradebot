# 자동매매 시스템 수정 작업지시서 (2026-04-06)

## 현재 상태 요약

"자동매매 시작" 버튼을 눌러도 **실제 매매가 한 번도 실행된 적 없음.**
워커 내부에서 매 사이클마다 5개 체크포인트가 전부 실패하여 조용히 스킵됨.

### 데이터 흐름 전체 그림

```
[관리자 대시보드] 자동매매 시작 버튼 클릭
       │
       ▼
[job-manager.ts] startJob('auto-trading')
  ❌ autoTradingEnabled를 true로 안 바꿈 ─── 수정①
       │
       ▼
[auto-trading-worker.ts] 매 사이클 실행
  ❌ userSettings.autoTradingEnabled === false → 스킵 ─── 수정①로 해결
  ❌ userSettings.kiwoomAppKey === NULL → 스킵 ─── 수정②
  ❌ ai_models.is_active === false → 아예 조회 안 됨 ─── 수정①에서 같이 해결
  ❌ auto_trading_settings 레코드 없음 → 기본값 만들고 return ─── 수정①에서 같이 해결
  ❌ condition_formulas 전부 isActive=false → 스킵 ─── 수정③
       │ (전부 통과해야 여기 도달)
       ▼
[trade-executor.service.ts] 매수/매도 실행
  ❌ accounts.find(a => a.isActive) — 계좌 선택이 임의적 ─── 수정④
  ❌ 선택된 계좌에 맞는 앱키를 못 찾음 ─── 수정②에서 같이 해결
       │
       ▼
[KiwoomService] → 집PC 에이전트로 프록시 → 키움 REST API 호출
```

### DB 현재 상태

| 항목 | 현재 값 | 필요 값 |
|------|---------|---------|
| `user_settings.auto_trading_enabled` | 전원 `false` | `true` |
| `user_settings.kiwoom_app_key` | 전원 `NULL` | (환경변수로 대체) |
| `user_settings.kiwoom_app_secret` | 전원 `NULL` | (환경변수로 대체) |

| `auto_trading_runs` | 0건 | 실행 기록 없음 |

## 수정① 워커 시작/중지 시 연쇄 활성화

### 문제
- `startJob`이 cron만 켜고, 워커가 돌기 위한 전제조건들을 켜지 않음
- 결과: 워커는 돌지만 매 사이클 "autoTradingEnabled=false"에서 스킵

### 파일: `server/job-manager.ts` — 90~106줄 `startJob()`

현재:
```typescript
startJob(id: string): { success: boolean; message: string } {
  // ...
  if (id === 'auto-trading') {
    autoTradingWorker.startTradingJob(schedule);
    return { success: true, message: `자동매매 워커를 시작했습니다.` };
  }
}
```

수정 (async 변환 + 연쇄 활성화):
```typescript
async startJob(id: string): Promise<{ success: boolean; message: string }> {
  // ...
  if (id === 'auto-trading') {
    // 1) 모든 AI 모델 활성화
    const allModels = await storage.getAllAiModels();
    for (const model of allModels) {
      if (!model.isActive) {
        await storage.updateAiModel(model.id, { isActive: true });
      }
      // 2) 모델별 auto_trading_settings가 없으면 기본값 생성
      const settings = await storage.getAutoTradingSettings(model.id);
      if (!settings) {
        await autoTradingWorker.executor.createDefaultSettings(model.id);
      }
      // 3) 해당 유저의 autoTradingEnabled = true
      await storage.updateUserSettings(model.userId, { autoTradingEnabled: true });
    }
    autoTradingWorker.startTradingJob(schedule);
    return { success: true, message: `자동매매 워커를 시작했습니다.` };
  }
}
```

### 파일: `server/job-manager.ts` — 108~117줄 `stopJob()`

수정 (async 변환 + 연쇄 비활성화):
```typescript
async stopJob(id: string): Promise<{ success: boolean; message: string }> {
  if (id === 'auto-trading') {
    const allModels = await storage.getAllAiModels();
    for (const model of allModels) {
      await storage.updateUserSettings(model.userId, { autoTradingEnabled: false });
    }
    autoTradingWorker.stopTradingJob();
    return { success: true, message: '자동매매 워커를 중지했습니다.' };
  }
}
```

### 파일: `server/routes/admin.routes.ts` — 15~22줄

현재 동기 호출 → `await` 추가:
```typescript
app.post('/api/admin/jobs/:id/start', isAuth, async (req, res) => {
```

## 수정⑤ 자동매매 비중/가중치 설정 UI 추가

### 문제
- `auto_trading_settings` 테이블에 아래 필드들이 존재하지만 컨트롤하는 UI가 없음:
  - `themeWeight` (테마 가중치, 기본 20%)
  - `newsWeight` (뉴스 가중치, 기본 15%)
  - `financialsWeight` (재무 가중치, 기본 25%)
  - `liquidityWeight` (유동성 가중치, 기본 20%)
  - `institutionalWeight` (기관 가중치, 기본 20%)
  - `defaultPositionSize` (기본 매매금액, 기본 100만원)
  - `maxPositionSize` (최대 매매금액, 기본 1000만원)
  - `maxDailyTrades` (일일 최대 거래 횟수, 기본 5회)
  - `minAiConfidence` (AI 최소 신뢰도, 기본 70%)
  - `rainbowLineSettings` (레인보우 10단계별 매수/매도 비중)
  - `requireGoodFinancials`, `requireHighLiquidity`, `requireMarketIssue`
  - `enableDynamicExit`, `stalePeriodDays`, `surgeThreshold`, `volumeSpikeMultiplier`
- API 엔드포인트도 없음 (설정 조회/수정 API가 존재하지 않음)

### 작업 내용

**1) API 엔드포인트 추가 (`server/routes/` 내)**

```
GET    /api/ai/models/:modelId/trading-settings    → 설정 조회
PUT    /api/ai/models/:modelId/trading-settings    → 설정 수정 (전체)
PATCH  /api/ai/models/:modelId/trading-settings    → 설정 부분 수정
```

**2) 설정 화면 신규 생성**

자동매매 페이지(`auto-trading.tsx`)에서 AI 모델을 선택하면 나타나는 설정 패널을 추가.
또는 설정 페이지(`settings`) 하위에 "자동매매 설정" 탭 추가.

**포함할 UI 요소:**

| 섹션 | 컨트롤 | DB 필드 |
|------|--------|---------|
| 매매 계좌 | 셀렉트 (계좌 목록) | `ai_models.config.accountId` |
| 기본 매매금액 | 숫자 입력 | `defaultPositionSize` |
| 최대 매매금액 | 숫자 입력 | `maxPositionSize` |
| 일일 최대 거래 | 숫자 입력 | `maxDailyTrades` |
| AI 최소 신뢰도 | 슬라이더 0~100% | `minAiConfidence` |
| AI 분석 가중치 | 5개 슬라이더 (합계 100%) | `themeWeight`, `newsWeight`, `financialsWeight`, `liquidityWeight`, `institutionalWeight` |
| 레인보우 차트 | 10줄 × 매수비중/매도비중 슬라이더 | `rainbowLineSettings` |
| 조건 필터 | 토글 3개 | `requireGoodFinancials`, `requireHighLiquidity`, `requireMarketIssue` |
| 동적 청산 | 토글 + 숫자 입력 3개 | `enableDynamicExit`, `stalePeriodDays`, `surgeThreshold`, `volumeSpikeMultiplier` |

**3) 가중치 합계 100% 검증**
- 5개 가중치 슬라이더의 합이 100%가 되도록 프론트엔드 검증

이전에 만들었지만 연결이 끊긴 항목들:

| 만들어진 것 | 연결 안 된 곳 | 이번에 해결 |
|------------|-------------|-----------|
| `auto_trading_settings` 테이블 스키마 | 레코드 생성 안 됨 + UI 없음 | 수정①⑤ |
| `ai_models` 테이블 | `is_active` 켜는 로직 없음 | 수정① |
| `autoTradingEnabled` 필드 | 토글하는 로직 없음 | 수정① |
| `condition_formulas.is_active` | 활성화 경로 없음 | 수정③ |
| 계좌별 환경변수 키 | 워커가 DB에서만 읽음 | 수정② |
| 계좌 선택 | 임의 선택, 유저 제어 불가 | 수정④ |
| 가중치 필드 5개 | 설정 UI 없음 | 수정⑤ |
| 레인보우 라인 설정 | 설정 UI 없음 | 수정⑤ |

**수정 후에는 위 항목 전부가 UI → API → DB → 워커 → 실행까지 하나의 흐름으로 연결되어야 함.**
