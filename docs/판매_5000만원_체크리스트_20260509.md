# 5000만원 판매용 체크리스트 (지인/소개 기반 수기 판매)

작성일: 2026-05-09  
대상: `tradebot` 고가(5,000만원) 1:1 판매

## 1) 판매 전 필수 조건 (No-Go 기준)
- [ ] 모의투자 검증 리포트 3개월 이상 확보
- [ ] 실거래 소액 검증 리포트 1개월 이상 확보
- [ ] 최대 손실(MDD), 월별 변동성, 승률, 손익비 공개 가능
- [ ] 장애 복구 절차 문서화(재시작, 키 재연결, 로그 수집)
- [ ] 구매자 계정/키/계좌 분리 동작 검증 완료
- [ ] “수익 보장 없음” 및 손실 가능성 고지 문구 준비

## 2) 계약서 핵심 조항 (반드시 포함)
- [ ] 제품 범위: 제공 기능, 비제공 기능 명시
- [ ] 책임 범위: 투자손실 책임 제한 조항
- [ ] 금지 문구: “원금 보장”, “확정 수익” 불가
- [ ] 유지보수 범위: 버그 수정/기능 추가 구분
- [ ] 장애 대응 시간: 예) 치명 장애 24시간 내 1차 대응
- [ ] 환불 조건: 설치 완료 후 환불 가능/불가 기준 명시
- [ ] 양도/재판매 금지: 구매자 1인 사용 원칙
- [ ] 해지/정지: 라이선스 위반 시 정지 가능 조건

## 3) 라이선스/보안 최소 요건
- [ ] 사용자별 라이선스 키 발급
- [ ] 라이선스 만료/정지 처리 기능
- [ ] API 키 암호화 저장(평문 금지)
- [ ] 감사로그 저장(로그인, 키 변경, 주문 실행/중지)
- [ ] 원격 진단 로그 내보내기(사용자 동의 기반)

## 4) 인도(납품) 절차 체크리스트
- [ ] 구매자 PC에 설치(원격/방문)
- [ ] 사용자 계정 생성 및 승인 상태 확인
- [ ] 구매자 본인 API 키 입력/연결 테스트
- [ ] 모의투자 1차 실행 확인
- [ ] 실거래 전환은 별도 서면 동의 후 진행
- [ ] 인수인계 문서 전달(재시작/중지/로그 수집 방법)
- [ ] 최종 인수 확인서 서명

## 5) 운영 정책 (분쟁 예방)
- [ ] 공지 채널 1개 고정(카톡/메일 중 택1)
- [ ] 버전 업데이트 주기 고정(예: 월 1회)
- [ ] 긴급 패치 정책(보안/주문오류 우선)
- [ ] 사용자 과실 범위 정의(키 오입력, PC 종료 등)
- [ ] 복구 지원 범위 정의(원격 지원 시간대)

## 6) 성능 설명 시 금지/권장 문구
### 금지
- “무조건 돈 번다”
- “손실 안 난다”
- “원금 보장”

### 권장
- “백테스트/실거래 검증 수치를 공개하고, 손실 가능성을 전제로 운영”
- “자동매매는 시장 상황에 따라 성과 변동이 크며, 리스크 관리가 핵심”

## 7) 3단계 판매 전략 (현실적)
1. 베타 유료(소수): 2~3명, 저가로 안정성 검증
2. 정식 전환: 데이터/장애율/지원 부담 분석
3. 고가 판매(5,000만원): 계약서+운영체계+검증리포트 완비 후 진행

## 8) 최종 Go/No-Go
- [ ] 계약서 서명 완료
- [ ] 성능 리포트 전달 완료
- [ ] 리스크 고지 확인 완료
- [ ] 설치/연결/모의 테스트 완료
- [ ] 구매자 인수 확인 서명 완료
